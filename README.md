## Agentic development systems

I designed and maintain [`agent-dev-kit`](https://github.com/LFTPadilla/agent-dev-kit), a public MIT-licensed, multi-runtime agent development kit for Codex, Claude Code, Pi, and OpenCode.

The kit separates communication, planning, capabilities, verification, and safety policies. It includes:

- Reusable skills and runtime profiles for agent-assisted engineering.
- Adversarial pull-request review with independent refutation before reporting defects.
- Prompt-injection defenses and explicit trust-boundary guidance.
- Browser QA with deterministic Playwright checks, exploratory sessions, and Stagehand workflows.
- Skill provenance, licensing visibility, risk classification, and dependency tracking.
- Sandbox-policy contracts for filesystem, network, secrets, and destructive actions.
- Planted-bug evaluation cases that measure recall and false-positive behavior.

The central idea is simple: coding agents need engineering systems around them. Planning, implementation, verification, and safety should be explicit, repeatable, and measurable.
